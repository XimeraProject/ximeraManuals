        \maketitle

        To author using Ximera, you must have a \link[GitHub]{https://github.com}
        account. GitHub is a web platform where developers can store, share,
        and manage
        their code. GitHub uses \verb!git!, popular software for version control,
        to help
        teams work together simultaneously without overwriting each other's
        changes.
        GitHub has
        \begin{itemize}
            \item issue tracking,
            \item pull requests for proposing changes,
            \item the ability to merge code,
        \end{itemize}
        and other project management tools. It's like a shared folder for
        coding, designed to
        help teams work together and track progress. Go to
        \url{https://github.com} and
        either \textbf{sign-up} or \textbf{log-in}. Note, you must know your \textbf{username}
        and
        \textbf{password}, so store them in a safe place; like in a safe, or
        under your bed. 



        \section{Deploying content}
        After you have a GitHub account, you have some choices for how you deploy Ximera content.
        
\paragraph{Experts}  experienced with GitHub, VS Code, and Docker, can set up Ximera on
their own machine using local installations of this software. If you choose to follow this path, check out the repositories:
\begin{itemize}
    \item \url{https://github.com/ximeraProject/ximeraFirstSteps}
    \item \url{https://github.com/ximeraProject/ximeraNewProject}
\end{itemize}

\paragraph{Beginners (and experts!)} can use \link[Overleaf Premium]{https://www.overleaf.com} to effortlessly deploy Ximera documents.
Overleaf is a popular online \LaTeX\ editor. The premium features provide integration with GitHub. If you choose to follow this path, check 
out the repositories:
        \begin{itemize}
    \item \url{https://github.com/ximeraProject/ximeraFirstOverleafSteps}            %% 190% on my laptop screen
    \item \url{https://github.com/ximeraProject/ximeraNewOverleafProject}
\end{itemize}


\paragraph{First time Ximera authors} will find it easiest to use Overleaf Premium and the repository:
\begin{center}
     \url{https://github.com/ximeraProject/ximeraFirstOverleafSteps}            %% 190% on my laptop screen
\end{center}
In the remainder of this section, we will walk you through the steps to create your own copy of this repository, 
and start editing and deploying Ximera content.
